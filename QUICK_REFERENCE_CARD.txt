🚀 LAUNCH IN 7 STEPS (1-2 HOURS TOTAL)

STEP 1: Create Supabase Account (15 min)
├─ Go to: supabase.com
├─ Click "Start your project"
├─ Sign up (email or Google)
├─ Create new project
├─ Copy 3 keys and save them:
│  ├─ PROJECT URL (looks like https://xxxxx.supabase.co)
│  ├─ ANON KEY (long text starting with "ey...")
│  └─ SERVICE ROLE KEY (another "ey..." key)
└─ Save these 3 keys in a text file - you'll need them in Step 3

STEP 2: Load Database Schema (5 min)
├─ Go to Supabase dashboard
├─ Click "SQL Editor" (left sidebar)
├─ Click "New Query"
├─ Open file: SUPABASE_SCHEMA.sql (in your ga-conservative-action folder)
├─ Copy ALL the code from that file
├─ Paste into the SQL Editor box
├─ Click "Run" (▶️ button)
└─ Wait for: "Query complete" (green checkmark)

STEP 3: Add Credentials to App (5 min)
├─ Open folder: C:\Users\lijos\OneDrive\Desktop\GAGame\ga-conservative-action
├─ Find file: .env.local
├─ Open in Notepad
├─ Replace the placeholder text with your 3 keys from Step 1:
│  ├─ NEXT_PUBLIC_SUPABASE_URL = your PROJECT URL
│  ├─ NEXT_PUBLIC_SUPABASE_ANON_KEY = your ANON KEY
│  └─ SUPABASE_SERVICE_ROLE_KEY = your SERVICE ROLE KEY
├─ Save file (Ctrl+S)
└─ The app will automatically detect the changes

STEP 4: Restart Dev Server (2 min)
├─ Look at your terminal window
├─ Press Ctrl+C to stop the server
├─ Type: npm run dev
├─ Press Enter
└─ Wait for message: "ready - started server on 0.0.0.0:3000"

STEP 5: Seed Database (2 min)
├─ Open NEW terminal window
├─ Type: cd "C:\Users\lijos\OneDrive\Desktop\GAGame\ga-conservative-action"
├─ Paste: curl -X POST http://localhost:3000/api/seed -H "Authorization: Bearer dev-seed-key-change-in-production" -H "Content-Type: application/json"
├─ OR if curl doesn't work, use:
│  Invoke-WebRequest -Uri "http://localhost:3000/api/seed" -Method POST -Headers @{"Authorization"="Bearer dev-seed-key-change-in-production"; "Content-Type"="application/json"}
├─ Press Enter
└─ Wait 10-20 seconds

STEP 6: Test Your App (30 min)
├─ Open browser: http://localhost:3000
├─ Try signing up with email
├─ Pick a county
├─ Log an activity
├─ Check that points are awarded
├─ Refresh page - data should persist
└─ Test on mobile (use browser DevTools, F12)

STEP 7: Deploy to Internet (30 min - OPTIONAL)
├─ Create GitHub repo at github.com
├─ Push your code to GitHub
├─ Go to vercel.com
├─ Deploy the GitHub repo
├─ Add your 3 Supabase keys as environment variables
├─ Wait 3-5 minutes for deployment
└─ Your app is now live at your Vercel URL!

🚨 IF SOMETHING GOES WRONG

Error: "Cannot connect to database"
Fix: 1) Check your 3 keys in .env.local are correct
     2) Check for typos or extra spaces
     3) Restart dev server (Ctrl+C, then npm run dev)

Error: "Tables don't exist"
Fix: Go back to Step 2 and run SUPABASE_SCHEMA.sql again

Error: "curl: command not found"
Fix: Use PowerShell command instead (see Step 5)

Error: "localhost:3000 won't load"
Fix: Check your terminal for errors, restart with npm run dev

Error: "Cannot upload photos"
Fix: This is optional - it will work after setup

Can't remember a password?
Fix: Easy to reset in Supabase dashboard
