🔐 SECURITY & ACCESS CONTROL

ROLE-BASED ACCESS:

👑 ADMIN
  • Full access to all concerns (all levels)
  • Manage data sources
  • Configure automation rules
  • View all submissions
  • Access audit logs

🏛️ COUNTY COORDINATOR
  • Manage local concerns (their county only)
  • Approve/reject submissions (their county)
  • View state/national concerns (read-only)

🎯 COUNTY LEADER
  • Create new concerns (local only)
  • View all concerns (read-only)
  • Cannot delete or manage submissions

📝 VOLUNTEER
  • Submit concerns via activity form
  • View own submissions
  • Cannot edit/delete

🔒 DATA PROTECTION:
  ✅ Row-Level Security (RLS) policies
  ✅ Database encryption
  ✅ Audit logging of all changes
  ✅ No sensitive data exposed
